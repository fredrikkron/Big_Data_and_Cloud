# IaaS - SQL Server in Azure VMs

### What you do?
Renting a virtual machine in Azure and installing SQL Server on it. Kinda like managing an on-prem server but in cloud.

### Responsibilities
Azure takes care and handles:

    - hardware
    - networking
    - datacenter security

You handle:
    
    - OS updates and patching
    - Installation patching and upgrades on SQL Server
    - Backups, availability and disaster recovery
    - Tune the performance, monitor and scale

### IaaS is best when you want:

    - Full control and customization
    - Legacy applications that need specific configurations on OS/SQL Server

#

# PaaS - Azure SQL Database/Managed Instance

### What you do?
Azure provide you with a fully managed database service. The only thing you deal with is schemas, queries and data.

### Responsibilities
Azure takes care and handles:

    - OS and SQL engine patching
    - Automated backups and restore
    - Availability and disaster recovery
    - Built-in security (encryption and threat detection)

You handle:
    
    - Database design (schemas, tables, indexes)
    - Queries, stored procedures and business logic
    - Query tuning (a lot is already automated)

### IaaS is best when you want:

    - The maintenance overhead reduced
    - Easy scalability and built-in reliability
    - Teams to focus more on data and not infrastructure

| Responsibility                | IaaS (SQL on VM) | PaaS (SQL Database / MI) |
| ----------------------------- | ---------------- | ------------------------ |
| Hardware / Network            | Azure            | Azure                    |
| OS patching & updates         | **You**          | Azure                    |
| SQL Server installation       | **You**          | Azure                    |
| SQL patching & upgrades       | **You**          | Azure                    |
| Backups & restore             | **You**          | Azure                    |
| High availability / DR        | **You**          | Azure                    |
| Security (infrastructure)     | Azure            | Azure                    |
| Security (data access, roles) | **You**          | **You**                  |
| Database schema & queries     | **You**          | **You**                  |
| Performance tuning            | **You**          | Shared (Azure assists)   |

    Like an apartment - clean, repair and maintain it
