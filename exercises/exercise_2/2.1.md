# Deploying dashboard container to Azure Web App vs Azure Container Instance

Azure Container Instance allows to directly run Docker containers on Azure infrastructure without managing servers or orchestrators.


Any container image that can run on Azure Web App for Containers can also run on ACI as long as the correct environment settings are provided. (ports, variables, etc.)



| Feature          | **Azure Web App for Containers**                                                   | **Azure Container Instances (ACI)**                                                 |
| ---------------- | ---------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| **Use Case**     | Web apps and APIs with built-in scaling, continuous deployment, and custom domains | Simple, fast container execution without orchestration or hosting overhead          |
| **Persistence**  | Supports custom domains, SSL, staging slots, and integrated scaling                | Usually ephemeral; not ideal for long-term hosting (containers restart on redeploy) |
| **Scaling**      | Auto-scaling supported via App Service Plan                                        | Manual scaling (you can specify CPU/memory, but no auto-scale)                      |
| **Networking**   | Built-in load balancing and HTTPS                                                  | Simple public IP or private VNet integration                                        |
| **Integration**  | Tightly integrated with CI/CD (GitHub, DevOps)                                     | More suited for short-lived or batch workloads                                      |
| **Cost model**   | Based on App Service Plan (reserved capacity)                                      | Pay only for container runtime (per second)                                         |
| **Startup time** | Slightly longer due to App Service environment                                     | Very fast container startup                                                         |
| **Statefulness** | Supports mounted storage                                                           | Typically stateless (unless mounted to Azure File Share)                            |
| **Best for**     | Always-on web apps / dashboards needing continuous availability                    | Short-running tasks, testing, or lightweight dashboards                             |


ACI is faster and cheaper for short-lived/test deployments.
Azure Web App is more production-ready with built in autoscaling, HTTPS, domain names and monitoring.
