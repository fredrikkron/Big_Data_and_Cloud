| **Azure Service**                              | **Purpose / Description**                                                               | **AWS Equivalent**                                                                              | **GCP Equivalent**                                            |
| ---------------------------------------------- | --------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- | ------------------------------------------------------------- |
| **Azure Container Registry (ACR)**             | Private Docker container image registry for storing and managing container images       | **Amazon Elastic Container Registry (ECR)**                                                     | **Google Artifact Registry** *(or older: Container Registry)* |
| **Azure Container Instance (ACI)**             | Serverless container runtime — run containers without managing servers or orchestration | **AWS Fargate (with ECS)** or **AWS App Runner**                                                | **Google Cloud Run**                                          |
| **Azure Web App (App Service for Containers)** | Managed web hosting platform for apps and APIs (supports containers)                    | **AWS Elastic Beanstalk** *(for web apps)* or **AWS App Runner** *(for containerized web apps)* | **Google App Engine (Flexible Environment)**                  |
| **Azure File Share** | Fully managed cloud file shares accessible via SMB protocal (mountable from Windows, Linux, macOS)                    | **Amazon Elastic File System (EFS)** *(NFS-based)* or **Amazon FSx for Windows File Server** *(SMB-based)* | **Google File Store** *(NFS-based managed file storage)*                 |
